---
description: >-
  An agent writes a skill by its own ideas. The agent fills a name, a
  description, a when-to-use and instructions section by section. The words
  grow with every edit. The grown words pass what a human can review. The
  number of skills multiplies the growth. The unreviewed skill drifts from its
  purpose, then turns useless. This skill asks the agent to write a skill by
  the steps below, not by its own ideas.
---

Skill structure:
1. The description is the only frontmatter field.
2. The description is an SCQA opening structure: {context the reader already agrees with}. {the change that disrupts it}. {the issue it raises, stated or as its consequence}. {what resolves it}.
3. The instruction area holds only a header and a list.
4. The header holds the skill's purpose.
5. The list holds the steps, one action per step.
