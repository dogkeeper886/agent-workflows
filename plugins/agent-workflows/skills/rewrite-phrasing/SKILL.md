---
description: >-
  An agent rewrites a document's phrasing by its own ideas. The agent reads past
  its own verbal tics, filler words, loose phrases and negative sentences. The
  loose words bury each sentence's main character. The buried main character
  costs the reader a second read. This skill asks the agent to rewrite a
  document's phrasing by the steps below.
---

Rewrite sentences:
1. On the input text, skip headings, code blocks, code spans and commands.
2. On the remaining sentences, cut redundancy and bloat.
3. On the step 2 result, rewrite each sentence so its central character is the subject and its action is the verb.
4. On the step 3 result, rewrite each negative sentence in its affirmative form.
5. On the step 4 result, rewrite each sentence with a nominalization that hides an action, so the action is a verb.
6. Output the step 5 result.
