---
description: >-
  An agent reviews how a document looks by its own ideas. The agent formats
  section by section, adding bold and headings where each seems needed. Even
  spacing merges the groups, and bold on every line marks nothing. The reader
  cannot find the point without reading everything. This skill asks the agent
  to review how a document looks by the steps below, not by its own ideas.
---

Review how a document looks:
1. Mark what belongs together before reading any formatting.
2. Check the gap inside each group is smaller than the gap around it.
3. Count the bold, and dim the rest rather than raise the point.
4. Count the heading depths, two by default and three only where the content nests.
5. In HTML, check the heading levels follow the outline and CSS carries the weight.
6. Strip every `#`, `**` and `-` in your head, and check the page still reads.
7. Report with the `reporting-outcomes` skill, each finding with the step it failed and its smallest fix.
