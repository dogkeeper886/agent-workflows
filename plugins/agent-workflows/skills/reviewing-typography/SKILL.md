---
description: >-
  An agent reviews how a document looks by its own ideas. The agent formats
  section by section, adding bold and headings where each seems needed. Even
  spacing merges the groups, and bold on every line marks nothing. The reader
  cannot find the point without reading everything. This skill asks the agent
  to review how a document looks by the steps below, not by its own ideas.
---

Review how a document looks:
1. Make the point stand out by raising it and dimming the rest, and stand alone by separating it with space.
2. Title: use the one top heading to make the title stand out, and space to make it stand alone.
3. Section: use heading levels to follow the outline, two by default and three only where the content nests, and space to make each section stand alone.
4. Paragraph: use a paragraph to hold a topic, a list for parallel items, a table for items compared on the same columns, and space to make each one stand alone.
5. Clause: use bold to make the words the reader must not miss stand out, and a code span to mark literal text.
6. Zoom out to the whole document, and check nothing competes with the point.
7. Report with the `reporting-outcomes` skill, each finding with the step it failed and its smallest fix.
