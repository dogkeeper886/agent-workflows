---
description: >-
  Human attention is limited, so a reader wants the problem first. An agent
  designs a visual by its own ideas: it puts every fact on one screen, shows
  the full detail on every click and repeats a fact wherever it fits. The
  facts flood the screen, and the reader hunts for the problem. This skill
  guides the agent to layer the facts from a glance to detail, group them
  by kind and split each layer into its own output, with a tree of nodes and
  indicators, count chips, hover popovers, a drawer with folded rows and a
  lens that filters.
---

Design a visual's flow:
1. List each fact the user asks for.
2. Group the facts by kind.
3. Give each fact one layer: glance, hover, click or filter.
4. Fold each fact that is fine into a count chip or an indicator, so the glance shows only problems.
5. Draw what the facts describe as a tree of nodes, each with an indicator.
6. Preview each node in a hover popover.
7. Show each node's detail in the drawer, with what is fine folded into rows.
8. Put each other view of the facts behind a lens.
9. Check that each fact appears in one layer only.
10. Split each layer into its own output.
11. Draw each output with the `draw-svg-diagrams` skill.
12. Explain the flow in the session with the `draw-ascii-diagrams` skill.
13. Wait for the user to approve the flow before building it.
