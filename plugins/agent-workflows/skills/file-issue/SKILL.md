---
description: >-
  An agent files an issue by its own ideas. The agent rewrites each request
  in its own words. The rewritten request shifts the intent before anyone
  notices. The shifted issue drops the reasoning behind it. A cold agent
  picks the issue up and builds the shifted intent. The session log that
  carries the reasoning can also carry a secret into a public repository. This
  skill asks the agent to file an issue by the steps below, not by its own
  ideas.
---

File an issue:
1. Open the issue with an intro that follows the SCQA framework: situation, complication, question, answer.
2. When the session log holds a secret or private info, stop and ask the user.
3. Copy the session log raw into .sessions/ and link it from the intro, so the next agent reads the context behind it.
4. Show the user the intro and the link to the issue.
